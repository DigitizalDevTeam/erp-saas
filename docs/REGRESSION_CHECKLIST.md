# Regression Checklist (Pre / Post Update)

Use this checklist **before** merging or deploying an update, and **again after** the update.  
Mark each item **Pass** / **Fail** / **N/A**. **Fail on any P0 blocks release.**

---

## How to use

1. Run **P0 Smoke** every time (always).
2. Run module sections that touch the change, plus any historically fragile areas (POS QR, print layouts, Hotel Price per Period).
3. Re-run the same ticks after deploy.
4. File bugs for Fail items; do not close the release until P0 is green.
